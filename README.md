# 🚀 Sintelis Update Server & Desktop App Repository
Direktori kerja terpusat untuk pengembangan aplikasi desktop Sintelis Utility, peladen pembaruan otomatis (Cloudflare Auto-Updater), dan basis pengetahuan dokumentasi (Obsidian Vault).

## 📁 Struktur Folder
- `01_scripts_pendukung/` : Source code aplikasi, frontend Vite/React, backend Python, modul Timemark, dan skrip build.
- `02_server_update/` : Berkas server update aktif (port 8085), biner rilis `SintelisUtility.exe`, dan `version.json`.
- `03_vault_docs/` : Dokumentasi sistem, SOP rilis, catatan harian, dan dashboard Obsidian.
- `.obsidian/` : Konfigurasi workspace Obsidian.

## ⚡ Eksekusi Cepat
- Jalankan `build_and_deploy.bat` untuk mengompilasi dan merilis pembaruan baru secara otomatis.
- Buka folder ini di Obsidian untuk melihat Dashboard dan dokumentasi proyek.
