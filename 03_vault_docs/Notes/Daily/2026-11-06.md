## 🔍 Temuan Akar Masalah (Root Cause Analysis)

1. **Penyebab Fisik Kotak Mental ke Tengah (CSS Flexbox Specification):**
   - Di dalam `InlineTimemarkBox`, terdapat kode pembersihan DOM imperatif saat pointer up dan effect:
     ```javascript
     boxRef.current.style.left = '';
     boxRef.current.style.top = '';
     ```
   - Niat awal adalah mengembalikan kontrol inline style ke React. Namun, browser Chromium langsung mengevaluasi properti CSS yang bernilai string kosong `''` sebagai `top: auto` dan `left: auto`.
   - Karena kontainer induknya memiliki CSS:
     ```css
     display: inline-flex;
     align-items: center;
     justify-content: center;
     ```
     Sesuai aturan baku W3C Flexbox, setiap elemen `position: absolute` dengan `top: auto` & `left: auto` di dalam flex container otomatis ditarik dan dikunci paksa tepat di titik tengah (50% horizontal & 50% vertikal).
2. **Penyebab Saling Menimpa Antar Foto:**
   - **Variabel Global `lastTimemarkPos`:** Re-render akibat Foto 50 mengubah `lastTimemarkPos`, yang kemudian dibaca oleh Foto 0 sebagai fallback.
   - **Key Remounting:** Penggunaan `key` yang mengandung `photoObj?.meta?.yPos` menyebabkan komponen di-*unmount* dan di-*remount* kembali ke nilai lama sebelum API selesai disimpan.
   - **Default `applyToFolder = true` di Modal:** Pada foto pertama (`0.jpg`), modal editor mengaktifkan centang *"Terapkan ke seluruh foto"* secara default, sehingga penyimpanan foto 0 menimpa metadata foto 50 dan 100 di backend.

## 🛠️ Perbaikan Teknis yang Telah Diterapkan

1. **Penetapan Nilai Persentase Eksplisit ke DOM:**
   - Menghapus pembersihan string `''` dan menggantinya dengan koordinat persentase langsung:
     ```javascript
     if (boxRef.current) {
       boxRef.current.style.left = `${(lastNormX / 300) * 100}%`;
       boxRef.current.style.top = `${(lastNormY / 300) * 100}%`;
     }
     ```
2. **Isolasi State Mandiri per Foto (`photoCoordsMap`):**
   - Dibuat state `photoCoordsMap` di level `GalleryPanel` dan `BatchDateEditorPanel`.
   - Koordinat yang baru digeser langsung dikunci di memori lokal foto tersebut, sehingga Foto 0 tidak akan pernah terpengaruh oleh aktivitas pada Foto 50/100.
3. **Penguncian Bounding Box 1:1 (`display: inline-block`):**
   - Mengubah wrapper pembungkus gambar menjadi `display: inline-block` dan menghitung drag langsung dari dimensi fisik rendered `<img>` (`clientWidth` & `clientHeight`).
4. **Fast Targeted Refresh (`refreshSinglePhotoCard`):**
   - Hanya merefresh objek 1 kartu foto lokal di memori dan menginjeksi cache buster `?_v=timestamp`, menghilangkan lag pemindaian network drive.
5. **Ultra-Compact Header & Collapsible Filter Bar:**
   - Header Bento mendukung mode collapse ramping (~38px) dengan persistensi di `localStorage`.
   - Toolbar galeri dikonsolidasikan menjadi 1 baris ramping (~44px) dan bar filter dapat dibuka/tutup via tombol `[⚡ Filter]`.
6. **Perluasan ke Menu Ganti Tanggal Foto (`BatchDateEditorPanel.jsx`):**
   - Seluruh logika isolasi koordinat per foto dan perbaikan DOM style diterapkan setara pada menu Ganti Tanggal Foto.
